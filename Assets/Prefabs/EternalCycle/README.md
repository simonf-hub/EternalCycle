# Eternal Cycle prefabs

| Folder | Shared assets |
| --- | --- |
| [Arena](Arena) | Angel and Devil, Colosseum backdrop, scrolling platforms, follower, four god gifts, and Ares’s homing bomb |
| [Environment](Environment) | Floors, hidden platforms, and breakable walls |
| [Cooperative](Cooperative) | Shared exits, checkpoints, pressure plates, and paired gates |
| [Art](Art) | Placeholder sprites, ability icons, and line material |
| [Players](Players) and [Pickups](Pickups) | Original prototype assets |

Use Prefab Mode to edit a shared asset, or select a prefab instance in a scene to change its placement. For new artwork, update the Sprite Renderers or visual children and keep gameplay components, collision shapes, and scene references in place. Instance overrides take precedence over changes in the prefab.

See the [campaign authoring guide](../../DivineSense/README.md) for layout and story settings.
